# Test Cases: ค้นหารายวิชาและเลือก Section (U4)
ขอบเขต: U4 ค้นหารายวิชาตามคีย์เวิร์ด/ชั้นปีที่แนะนำ และดู Section ของรายวิชา  
แหล่งอ้างอิง: `CourseController`, `CourseControllerMockTests`, `courses.html`, `course-detail.html`

## ขอบเขตฟังก์ชันที่เกี่ยวข้อง

| รหัส | ฟังก์ชัน | พฤติกรรมที่ตรวจ |
|---|---|---|
| F1 | ค้นหารายวิชา | ค้นหาจากรหัสหรือชื่อวิชา และกรองตามชั้นปีที่แนะนำ |
| F2 | แสดงรายการเริ่มต้น | เมื่อไม่ระบุคีย์เวิร์ดหรือส่งค่าว่าง ให้คืนรายการวิชา |
| F3 | ตรวจสอบชั้นปี | รับชั้นปีตั้งแต่ 1 ถึง 4; ค่าที่อยู่นอกช่วงต้องถูกปฏิเสธ |
| F4 | ดูรายละเอียดและ Section | แสดงข้อมูลรายวิชาและ Section พร้อมรหัส Section และชื่อผู้สอน |
| F5 | จัดการรายวิชาที่ไม่พบ | เมื่อไม่พบรหัสวิชา ให้ตอบกลับ HTTP 404 |

## ข้อมูลทดสอบและเงื่อนไขตั้งต้น

- ใช้ `MockMvc` เรียก `CourseController` และ mock `JdbcTemplate`; ไม่ต้องเชื่อมต่อฐานข้อมูล
- กรณีค้นหาสำเร็จกำหนดข้อมูลจำลองเป็น CS101, ชั้นปีแนะนำ 1 และมี 2 Sections
- กรณีดูรายละเอียดส่งรหัส `cs101` ตัวพิมพ์เล็ก เพื่อทดสอบการปรับรหัสก่อนค้นหา
- สถานะ: **ผ่าน** = ยืนยันจากการรันทดสอบ, **ไม่ผ่าน** = ผลต่างจากที่คาด, **ยังไม่รัน** = ยังไม่มีผล execution
