U6: ให้คะแนนรายวิชาตามหัวข้อที่กำหนด

ขอบเขต: Test case ต่อไปนี้ยึด U6 ใน sequence diagram โดยใช้คะแนน 3 ระดับ 0.0, 50.0, 100.0 เหมือนกันทุกหัวข้อ รวมกรณี “ไม่แน่ใจ” = null, การตรวจสิทธิ์ และการจัดการข้อผิดพลาด

กติกาคะแนน:
- แนวทางการสอน: เน้นทฤษฎี = 0.0, สมดุล = 50.0, เน้นปฏิบัติ = 100.0
- สัดส่วนการวัดผลและตัดเกรด: เน้นคะแนนสอบ = 0.0, สมดุล = 50.0, เน้นโครงงาน = 100.0
- ความเร็วในการสอน: สอนช้า = 0.0, ปานกลาง = 50.0, สอนเร็ว = 100.0
- รูปแบบงาน: เน้นงานเดี่ยว = 0.0, สมดุล = 50.0, เน้นงานกลุ่ม = 100.0
- ปริมาณงาน: งานน้อย = 0.0, ปริมาณงานสมดุล = 50.0, งานเยอะ = 100.0
- ทุกกรณีส่งสำเร็จต้องเลือกให้ครบ 5 หัวข้อ และมีอย่างน้อย 1 หัวข้อที่เป็นคะแนนจริง ไม่ใช่ “ไม่แน่ใจ”

TC1: นักศึกษาสามารถส่งข้อมูลประเมินบางหัวข้อและเลือก “ไม่แน่ใจ” ในหัวข้อที่เหลือได้

Test objective: ทดสอบการส่งคะแนนจริงเพียงบางหัวข้อ โดยยังเลือกคำตอบครบทุกหมวดตามเงื่อนไขใน Diagram

Input: แนวทางการสอน = เน้นปฏิบัติ; อีก 4 หัวข้อ = ไม่แน่ใจ; มีข้อความรีวิว

Script:
- เข้าสู่ระบบด้วยบัญชีนักศึกษา CSTU ที่มีสิทธิ์รีวิวและยังไม่เคยรีวิววิชานี้
- เปิดฟอร์ม Review ของรายวิชา CS261 Introduction to Software Engineering
- เลือก “เน้นปฏิบัติ” ในแนวทางการสอน และเลือก “ไม่แน่ใจ” ในอีก 4 หัวข้อ
- กรอกข้อความรีวิวที่ไม่ใช่ช่องว่าง
- กดปุ่ม “ส่ง”

Expected output: ระบบส่งสำเร็จ (HTTP 201); แนวทางการสอนถูกบันทึกเป็น 100.0; อีก 4 หัวข้อเป็น null และไม่นำไปคำนวณสถิติ

TC2: ระบบบันทึกตัวเลือก “ไม่แน่ใจ” เป็น null ได้

Test objective: ทดสอบการบันทึก “ไม่แน่ใจ” ร่วมกับคะแนนจริงในหัวข้ออื่น

Input: แนวทางการสอน = ไม่แน่ใจ, สัดส่วนการวัดผล = สมดุล, ความเร็วในการสอน = ไม่แน่ใจ, รูปแบบงาน = เน้นงานเดี่ยว, ปริมาณงาน = ไม่แน่ใจ; มีข้อความรีวิว

Script:
- เข้าสู่ระบบด้วยบัญชีนักศึกษาที่มีสิทธิ์รีวิวและเปิดฟอร์มรายวิชา
- เลือกตัวเลือกตาม Input ให้ครบทั้ง 5 หัวข้อ
- กรอกข้อความรีวิวและกด “ส่ง”
- ตรวจข้อมูลที่บันทึกใน API/ฐานข้อมูลทดสอบ

Expected output: ส่งสำเร็จ; “ไม่แน่ใจ” จัดเก็บเป็น null; สมดุลเป็น 50.0 และเน้นงานเดี่ยวเป็น 0.0

TC3: ระบบแปลงตัวเลือกทั้ง 3 ระดับของทุกหัวข้อได้ถูกต้อง

Test objective: ทดสอบ mapping ค่าต่ำสุด ค่ากลาง และค่าสูงสุดสำหรับทุกหัวข้อ

Input: ตัวเลือก 3 ระดับของทั้ง 5 หัวข้อ โดยทดสอบแต่ละระดับแยกชุด

Script:
- เข้าสู่ระบบด้วยบัญชีที่มีสิทธิ์และยังไม่เคยรีวิววิชาที่ใช้ทดสอบ
- เลือกตัวเลือกค่าต่ำสุดของทุกหัวข้อ กรอกข้อความและส่ง
- ใช้ผู้ใช้/วิชาทดสอบชุดใหม่ เลือกค่ากลางของทุกหัวข้อ กรอกข้อความและส่ง
- ใช้ผู้ใช้/วิชาทดสอบชุดใหม่ เลือกค่าสูงสุดของทุกหัวข้อ กรอกข้อความและส่ง
- ตรวจค่าที่ API/ฐานข้อมูลได้รับ

Expected output: ทั้ง 5 หัวข้อถูกแปลงเป็น 0.0, 50.0 และ 100.0 ตามชุดทดสอบตามลำดับ โดยไม่สลับหัวข้อ
