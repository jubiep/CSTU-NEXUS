## ข้อมูลทดสอบและเงื่อนไขตั้งต้น

- ใช้ปีทดสอบ 2026 (พ.ศ. 2569) สำหรับการคำนวณ: รหัสขึ้นต้น `68` = ชั้นปี 2, `67` = ชั้นปี 3, `66` = ชั้นปี 4, `65` = ชั้นปี 5 ตามสูตรปัจจุบัน
- เตรียมวิชาที่ `recommended_year` เป็น 1, 2 และ 4; ผู้ใช้ที่มี session ถูกต้องและมีแถว `mock_user`; กรณีซ้ำให้เตรียมรีวิวเดิมของผู้ใช้ในวิชาเดียวกัน
- ทุกกรณีที่ต้องยิง API ต้องใช้ฐานข้อมูลทดสอบแยกและ session ทดสอบ ไม่ใช้บัญชี/ข้อมูลจริง
- สถานะ: **ผ่าน** = มีผลจากการรันยืนยัน, **ไม่ผ่าน** = พบผลต่างจากที่คาด, **ยังไม่รัน** = ยังไม่มีผล execution
