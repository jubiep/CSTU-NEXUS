# Test Cases: U6 ให้คะแนนรายวิชาตามหัวข้อที่กำหนด

วันที่จัดทำ: 15 พฤศจิกายน 2569  
ขอบเขต: ตรวจการเลือกคะแนน 5 หัวข้อ การแปลงคะแนนสเกล 0–100 การส่งรีวิว และการจัดการข้อผิดพลาด ตาม U6 ใน sequence diagram  
แหล่งอ้างอิง: `sequence-diagrams.md` (U6), `frontend/pages/write-review.html`, `frontend/app.js`, `ReviewController`, `ReviewService`, `backend/database/init.sql`

## กติกาคะแนนตาม Diagram

ทุกหัวข้อมี 3 ระดับ: ค่าต่ำสุด = 0.0, ค่ากลาง = 50.0, ค่าสูงสุด = 100.0 และ “ไม่แน่ใจ” หรือไม่ได้เลือก = `null` ในแต่ละรีวิวต้องเลือกให้ครบทั้ง 5 หัวข้อ และต้องมีอย่างน้อย 1 หัวข้อที่เป็นคะแนนจริง (ไม่ใช่ “ไม่แน่ใจ”)

| หัวข้อ | 0.0 | 50.0 | 100.0 |
|---|---|---|---|
| แนวทางการสอน | เน้นทฤษฎี | สมดุล | เน้นปฏิบัติ |
| สัดส่วนการวัดผลและตัดเกรด | เน้นคะแนนสอบ | สมดุล | เน้นโครงงาน |
| ความเร็วในการสอน | สอนช้า | ปานกลาง | สอนเร็ว |
| รูปแบบงาน | เน้นงานเดี่ยว | สมดุล | เน้นงานกลุ่ม |
| ปริมาณงาน | งานน้อย | ปริมาณงานสมดุล | งานเยอะ |

## เงื่อนไขตั้งต้น

- ใช้ฐานข้อมูลและ session สำหรับทดสอบเท่านั้น
- กรณีส่งสำเร็จต้องใช้ผู้ใช้ที่ล็อกอิน มีสิทธิ์ตามชั้นปี และยังไม่เคยรีวิววิชานั้น
- สถานะอ้างอิงผลจาก MockMvc, Node VM harness และ PostgreSQL 17 disposable ตาม Execution Log ด้านล่าง
